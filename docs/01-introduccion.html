Tema 01: Introducción a PostgreSQL

Aprende los fundamentos de PostgreSQL, su historia, características y por qué es una de las bases de datos más populares del mundo.

1.1 ¿Qué es PostgreSQL?

PostgreSQL es un sistema de gestión de bases de datos relacional de código abierto (RDBMS) conocido por su robustez, confiabilidad y cumplimiento de estándares SQL.

Características Principales

  • Código Abierto: Licencia PostgreSQL, similar a BSD/MIT
  • ACID Compliance: Transacciones atómicas, consistentes, aisladas y duraderas
  • SQL Estándar: Cumplimiento extensivo de SQL:2016
  • MVCC: Control de concurrencia multiversión
  • Extensibilidad: Soporte para tipos de datos y funciones personalizadas
  • JSON Nativo: Soporte completo para documentos JSON

Comparación con otras Bases de Datos

Característica PostgreSQL MySQL MongoDB
Tipo Relacional (SQL) Relacional (SQL) Documentos (NoSQL)
Licencia PostgreSQL License GPL/Commercial SSPL/Commercial
Transacciones Completo ACID InnoDB: ACID Limitado
JSON JSONB optimizado JSON básico Nativo BSON

1.2 Historia de PostgreSQL

1986

POSTGRES

Michael Stonebraker inicia el proyecto POSTGRES en UC Berkeley como sucesor de Ingres.

1989

Primera Versión

Se lanza la primera versión de POSTGRES con soporte para tipos de datos extensibles.

1994

Postgres95

Andrew Yu y Jolly Chen agregan soporte para SQL, naciendo Postgres95.

1996

PostgreSQL 6.0

Se renombra oficialmente a PostgreSQL y se lanza como código abierto.

2024

PostgreSQL 16+

Versiones modernas con mejoras en rendimiento, replicación y características avanzadas.

1.4 Arquitectura Básica

Componentes Principales

📦 Postmaster

El proceso principal que gestiona el cluster de bases de datos. Se encarga de:

  • Aceptar conexiones de clientes
  • Crear procesos backend para cada conexión
  • Gestionar procesos de background
  • Coordinar el recovery después de fallos

⚙️ Backend Processes

Procesos individuales creados para cada conexión de cliente:

  • Ejecutan consultas SQL
  • Mantienen estado de transacción
  • Gestionan buffers y caché
  • Se destruyen al cerrar conexión

🔄 Background Processes

Procesos que mantienen el sistema funcionando:

  • Checkpointer: Guarda cambios en disco
  • WAL Writer: Escribe el log transaccional
  • Autovacuum: Limpieza automática
  • Stats Collector: Recopila estadísticas

💾 Storage

Componentes de almacenamiento físico:

  • Tablespaces: Ubicación física de datos
  • WAL (Write-Ahead Log): Durabilidad
  • Shared Buffers: Caché en memoria
  • Temp Files: Archivos temporales

1.5 Primeros Pasos

Conceptos Fundamentales

📁 Base de Datos

Una colección organizada de datos estructurados. En PostgreSQL, una instalación puede contener múltiples bases de datos.

-- Crear una base de datos
CREATE DATABASE mi_base_de_datos;

-- Conectarse a una base de datos
\c mi_base_de_datos;

-- Listar bases de datos
\l

📋 Tabla

Estructura que almacena datos en filas y columnas. Cada tabla tiene un nombre único dentro de su esquema.

-- Crear una tabla
CREATE TABLE usuarios (
    id SERIAL PRIMARY KEY,
    nombre VARCHAR(100) NOT NULL,
    email VARCHAR(255) UNIQUE NOT NULL,
    fecha_registro TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- Ver estructura de tabla
\d usuarios

📝 Fila (Tuple)

Un registro individual en una tabla. Cada fila representa una entidad completa con valores para cada columna.

-- Insertar una fila
INSERT INTO usuarios (nombre, email) 
VALUES ('Juan Pérez', 'juan@email.com');

-- Consultar filas
SELECT * FROM usuarios;

📊 Columna (Atributo)

Un campo específico en una tabla que define el tipo de dato que puede almacenar.

-- Agregar una columna
ALTER TABLE usuarios 
ADD COLUMN telefono VARCHAR(20);

-- Modificar una columna
ALTER TABLE usuarios 
ALTER COLUMN nombre TYPE TEXT;

1.6 Herramientas y Ecosistema

Clientes y Herramientas de Administración

Herramienta Tipo Descripción
psql Línea de comandos Cliente oficial de terminal. Potente y disponible en todos los sistemas.
pgAdmin 4 GUI Web Herramienta oficial de administración. Completa y multiplataforma.
DBeaver GUI Desktop Cliente universal de bases de datos. Soporta múltiples sistemas.

Extensiones Populares

  • PostGIS: Soporte para datos geoespaciales

  • uuid-ossp: Generación de UUIDs

1.7 Ejercicios Prácticos

📝 Ejercicio 1: Explorar psql

Objetivo: Familiarizarse con la línea de comandos de PostgreSQL.

  1. Abre la terminal y ejecuta psql --version para verificar la instalación
  2. Conéctate a PostgreSQL: psql -U postgres
  3. Ejecuta \l para listar las bases de datos
  4. Ejecuta \? para ver todos los comandos disponibles
  5. Sal de psql con \q

📝 Ejercicio 2: Crear tu Primera Base de Datos

Objetivo: Crear una base de datos y una tabla simple.

  1. Conéctate a PostgreSQL
  2. Crea una base de datos: CREATE DATABASE biblioteca;
  3. Conéctate a ella: \c biblioteca
  4. Crea una tabla de libros con los campos: id, titulo, autor, año, isbn
  5. Inserta 3 libros de ejemplo
  6. Consulta todos los libros

📝 Ejercicio 3: Explorar pgAdmin

Objetivo: Conocer la interfaz gráfica de administración.

  1. Abre pgAdmin 4 en tu navegador
  2. Conéctate al servidor PostgreSQL
  3. Navega por el árbol de objetos
  4. Abre el Query Tool
  5. Ejecuta consultas SQL básicas
  6. Explora las herramientas de visualización

1.8 Resumen del Tema

Puntos Clave

  • PostgreSQL es un RDBMS de código abierto con más de 35 años de desarrollo
  • Cumple con el estándar SQL y soporta características avanzadas como JSON y datos geoespaciales
  • Utiliza una arquitectura cliente-servidor con procesos múltiples
  • El ecosistema incluye herramientas como psql, pgAdmin y extensiones como PostGIS
  • Es ideal para aplicaciones que requieren integridad de datos y consultas complejas
