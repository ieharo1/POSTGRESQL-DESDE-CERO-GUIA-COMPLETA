Tema 02: Instalación de PostgreSQL

Aprende a instalar PostgreSQL en Windows, Linux y macOS, además de configurar las herramientas de desarrollo.

2.1 Instalación en Windows

Paso 1: Descargar el Instalador

Visita el sitio oficial de PostgreSQL y descarga el instalador para Windows:

  1. Ve a postgresql.org/download/windows
  2. Haz clic en "Download the installer"
  3. Selecciona la versión más reciente (actualmente PostgreSQL 16)
  4. Descarga el instalador de EnterpriseDB

Paso 2: Ejecutar el Instalador

Sigue estos pasos durante la instalación:

  1. Directorio de instalación: Deja el predeterminado (C:\Program Files\PostgreSQL\16)
  2. Componentes: Selecciona todos (PostgreSQL Server, pgAdmin 4, Command Line Tools)
  3. Directorio de datos: Deja el predeterminado
  4. Contraseña: Establece una contraseña segura para el usuario postgres (¡guárdala!)
  5. Puerto: Deja 5432 (puerto por defecto)
  6. Locale: Selecciona tu configuración regional

Paso 3: Verificar la Instalación

# Abre PowerShell o CMD y ejecuta:
psql --version

# Deberías ver algo como:
# psql (PostgreSQL) 16.0

# Conéctate a PostgreSQL
psql -U postgres

# Ingresa la contraseña que estableciste

⚠️ Importante: La contraseña del usuario postgres es crítica. Si la olvidas, tendrás que resetearla editando pg_hba.conf

2.2 Instalación en Linux (Ubuntu/Debian)

Método 1: Usando el Repositorio Oficial

# 1. Importar la clave del repositorio
wget --quiet -O - https://www.postgresql.org/media/keys/ACCC4CF8.asc | sudo apt-key add -

# 2. Agregar el repositorio
sudo sh -c 'echo "deb http://apt.postgresql.org/pub/repos/apt/ $(lsb_release -cs)-pgdg main" > /etc/apt/sources.list.d/pgdg.list'

# 3. Actualizar paquetes
sudo apt-get update

# 4. Instalar PostgreSQL
sudo apt-get install -y postgresql postgresql-contrib

# 5. Verificar estado
sudo systemctl status postgresql

# 6. Habilitar inicio automático
sudo systemctl enable postgresql

Método 2: Usando Paquetes del Sistema

# Instalación rápida (versión del repositorio de Ubuntu)
sudo apt update
sudo apt install -y postgresql postgresql-contrib

Configuración Inicial en Linux

# Cambiar contraseña del usuario postgres
sudo -u postgres psql
ALTER USER postgres PASSWORD 'tu_contraseña_segura';
\q

# Crear un usuario de base de datos
sudo -u postgres createuser --interactive

# Crear una base de datos
sudo -u postgres createdb mi_base

2.3 Instalación en macOS

Método 1: Usando Homebrew (Recomendado)

# 1. Instalar Homebrew (si no lo tienes)
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

# 2. Instalar PostgreSQL
brew install postgresql@16

# 3. Iniciar el servicio
brew services start postgresql@16

# 4. Verificar estado
brew services list

# 5. Crear usuario
createuser --superuser $USER

Método 2: Usando Postgres.app

  1. Descarga Postgres.app desde postgresapp.com
  2. Arrastra la aplicación a la carpeta Aplicaciones
  3. Abre Postgres.app
  4. Haz clic en "Initialize" para crear un nuevo servidor

2.4 Instalación de pgAdmin 4

En Windows

pgAdmin 4 se instala automáticamente con el instalador de PostgreSQL. Para acceder:

  1. Busca "pgAdmin 4" en el menú Inicio
  2. Se abrirá en tu navegador predeterminado
  3. Establece una contraseña maestra la primera vez

En Linux

# Instalar pgAdmin 4
sudo apt-get install pgadmin4

# O usar la versión web
sudo apt-get install pgadmin4-web

Configurar Conexión en pgAdmin

  1. Haz clic derecho en "Servers" → "Create" → "Server"
  2. En la pestaña "General", pon un nombre (ej: "PostgreSQL Local")
  3. En "Connection":
    • Host: localhost
    • Port: 5432
    • Maintenance database: postgres
    • Username: postgres
    • Password: tu contraseña
  4. Haz clic en "Save"

2.5 Configuración Post-Instalación

Archivos de Configuración Importantes

Archivo Ubicación Típica Propósito
postgresql.conf /etc/postgresql/16/main/ (Linux)
C:\Program Files\PostgreSQL\16\data\ (Windows)		 Configuración principal del servidor
pg_hba.conf Misma ubicación Control de acceso de clientes
pg_ident.conf Misma ubicación Mapeo de usuarios

Configuraciones Recomendadas

# En postgresql.conf:

# Memoria compartida (25% de RAM para servidores dedicados)
shared_buffers = 2GB

# Memoria para work mem (para operaciones de ordenamiento)
work_mem = 64MB

# Cache para consultas
effective_cache_size = 6GB

# Log de consultas lentas (más de 1 segundo)
log_min_duration_statement = 1000

# Habilitar logging
logging_collector = on
log_directory = 'log'
log_filename = 'postgresql-%Y-%m-%d_%H%M%S.log'

Reiniciar PostgreSQL después de cambios

# Windows (PowerShell como Administrador)
Restart-Service postgresql-x64-16

# Linux
sudo systemctl restart postgresql

# macOS (Homebrew)
brew services restart postgresql@16

2.6 Solución de Problemas Comunes

Problema: "Password authentication failed"

# Solución: Editar pg_hba.conf
# Cambiar de "scram-sha-256" a "md5" o "trust" (solo desarrollo)

# En Windows: C:\Program Files\PostgreSQL\16\data\pg_hba.conf
# En Linux: /etc/postgresql/16/main/pg_hba.conf

# Cambiar esta línea:
host    all             all             127.0.0.1/32            scram-sha-256
# Por esta:
host    all             all             127.0.0.1/32            md5

# Reiniciar PostgreSQL

Problema: "Could not connect to server"

# Verificar si PostgreSQL está corriendo
# Windows
Get-Service postgresql*

# Linux
sudo systemctl status postgresql

# Verificar puerto
netstat -an | grep 5432

Problema: "Role does not exist"

# Crear el rol/usuario
CREATE ROLE nombre_usuario WITH LOGIN PASSWORD 'contraseña';

# Dar permisos
GRANT ALL PRIVILEGES ON DATABASE nombre_db TO nombre_usuario;

2.7 Ejercicios Prácticos

📝 Ejercicio 1: Instalación Completa

Objetivo: Instalar PostgreSQL y pgAdmin en tu sistema.

  1. Descarga e instala PostgreSQL según tu sistema operativo
  2. Establece una contraseña segura para postgres
  3. Instala pgAdmin 4
  4. Configura una conexión en pgAdmin
  5. Conéctate exitosamente al servidor

📝 Ejercicio 2: Verificación desde Terminal

Objetivo: Familiarizarse con psql desde línea de comandos.

  1. Abre terminal/PowerShell/CMD
  2. Ejecuta psql --version
  3. Conéctate: psql -U postgres
  4. Ejecuta SELECT version();
  5. Ejecuta \l para listar bases de datos
  6. Sal con \q

📝 Ejercicio 3: Crear Usuario y Base de Datos

Objetivo: Gestionar usuarios y bases de datos.

  1. Conéctate como postgres
  2. Crea un usuario: CREATE USER dev_user WITH PASSWORD 'dev123';
  3. Crea una base de datos: CREATE DATABASE mi_proyecto OWNER dev_user;
  4. Conéctate a la nueva base: \c mi_proyecto
  5. Verifica los privilegios

2.8 Resumen del Tema

Puntos Clave

  • PostgreSQL está disponible para Windows, Linux y macOS
  • El instalador oficial incluye pgAdmin 4 para administración gráfica
  • La contraseña del usuario postgres debe guardarse de forma segura
  • Los archivos de configuración principales son postgresql.conf y pg_hba.conf
  • psql es la herramienta de línea de comandos oficial
