¿Qué es PostgreSQL?

🗄️

Sistema de Gestión de Bases de Datos

PostgreSQL es un sistema de gestión de bases de datos relacional de código abierto, conocido por su robustez, confiabilidad y cumplimiento de estándares SQL.

⚡

Para Qué Sirve

Se utiliza para almacenar, organizar y recuperar datos en aplicaciones web, sistemas empresariales, análisis de datos y aplicaciones de misión crítica.

🔧

Características Principales

Soporta JSON, índices avanzados, transacciones ACID, stored procedures, triggers, vistas materializadas y extensiones personalizables.

💡 ¿Sabías qué?

PostgreSQL es considerado el RDBMS de código abierto más avanzado del mundo. Su nombre proviene de "Post-Ingres", siendo Ingres un sistema de bases de datos desarrollado en UC Berkeley en los años 60-70.

Arquitectura de PostgreSQL

PostgreSQL utiliza una arquitectura cliente-servidor con procesos múltiples para manejar conexiones y operaciones.

Cliente / Aplicación

psql, pgAdmin, aplicaciones, drivers

⬇️

Postmaster

Proceso principal que gestiona el cluster

⬇️

Backend Processes

Procesos por conexión (query executor)

⬇️

Storage Engine

Tablas, índices, WAL, buffer cache

📊 Procesos Background

  • Checkpointer - Guarda cambios en disco
  • WAL Writer - Escribe el log transaccional
  • Autovacuum - Limpieza automática
  • Stats Collector - Recopila estadísticas

💾 Almacenamiento

  • Tablespaces - Ubicación física de datos
  • WAL (Write-Ahead Log) - Durabilidad
  • Shared Buffers - Caché en memoria
  • Temp Files - Archivos temporales

🔒 Concurrencia

  • MVCC - Control de concurrencia multiversión
  • Row-level locking - Bloqueo por fila
  • Transaction isolation - Aislamiento de transacciones
  • Savepoints - Puntos de guardado

🐘 Introducción a PostgreSQL

PostgreSQL es un sistema de gestión de bases de datos relacional de código abierto, conocido por su robustez, confiabilidad y cumplimiento de estándares SQL.

Historia:

PostgreSQL es considerado el RDBMS de código abierto más avanzado del mundo. Su nombre proviene de "Post-Ingres", siendo Ingres un sistema de bases de datos desarrollado en UC Berkeley en los años 60-70.

Características Principales:

  • ACID: Transacciones completamente ACID compliant
  • JSON: Soporte nativo para documentos JSON
  • Extensiones: Sistema de extensiones personalizables
  • GIS: PostGIS para datos geoespaciales
💡 ¿Sabías qué?

PostgreSQL es usado por empresas como Apple, Instagram y Spotify para manejar datos críticos.

🔧 Instalación de PostgreSQL

En Windows:

  1. Descarga desde postgresql.org
  2. Ejecuta el instalador
  3. Configura la contraseña de postgres
  4. Instala pgAdmin (GUI)

En Linux (Ubuntu):

sudo apt update
sudo apt install postgresql postgresql-contrib
sudo systemctl start postgresql

En macOS:

brew install postgresql
brew services start postgresql

📦 Conceptos Básicos

Crear Base de Datos:

CREATE DATABASE mi_base_datos;
\c mi_base_datos;

Crear Tabla:

CREATE TABLE usuarios (
    id SERIAL PRIMARY KEY,
    nombre VARCHAR(100) NOT NULL,
    email VARCHAR(255) UNIQUE NOT NULL,
    fecha_registro TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

Tipos de Datos:

  • SERIAL: Autoincremental
  • VARCHAR(n): Texto de longitud variable
  • TEXT: Texto ilimitado
  • TIMESTAMP: Fecha y hora

💻 Consultas SQL

SELECT Básico:

SELECT * FROM usuarios;
SELECT nombre, email FROM usuarios WHERE id = 1;
SELECT COUNT(*) FROM usuarios;

JOINs:

-- INNER JOIN
SELECT u.nombre, p.titulo
FROM usuarios u
INNER JOIN posts p ON u.id = p.usuario_id;

-- LEFT JOIN
SELECT u.nombre, p.titulo
FROM usuarios u
LEFT JOIN posts p ON u.id = p.usuario_id;

Funciones de Agregación:

SELECT AVG(precio), MAX(precio), MIN(precio)
FROM productos;

✅ Buenas Prácticas

Índices:

-- Crear índice
CREATE INDEX idx_email ON usuarios(email);

-- Índice único
CREATE UNIQUE INDEX idx_usuario_email ON usuarios(email);

Vistas Materializadas:

CREATE VIEW vista_usuarios AS
SELECT u.nombre, COUNT(p.id) as posts
FROM usuarios u
LEFT JOIN posts p ON u.id = p.usuario_id
GROUP BY u.id;

EXPLAIN:

EXPLAIN ANALYZE SELECT * FROM usuarios WHERE email = 'test@email.com';

🚀 Casos Reales

Full-Text Search:

SELECT * FROM posts
WHERE to_tsvector('spanish', contenido) @@ to_tsquery('palabra');

JSONB:

Backup:

pg_dump -U postgres mi_base > backup.sql
psql -U postgres -d mi_base < backup.sql

Ejemplos de Código

Crear Base de Datos

CREATE DATABASE mi_base_datos;

\c mi_base_datos;

Crear Tabla

CREATE TABLE usuarios (
    id SERIAL PRIMARY KEY,
    nombre VARCHAR(100) NOT NULL,
    email VARCHAR(255) UNIQUE NOT NULL,
    fecha_registro TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    activo BOOLEAN DEFAULT true
);

Consulta con JOIN

SELECT u.nombre, p.titulo
FROM usuarios u
INNER JOIN publicaciones p ON u.id = p.usuario_id
WHERE u.activo = true
ORDER BY p.fecha DESC;

Función JSON

SELECT 
    nombre,
    datos->>'telefono' AS telefono
FROM usuarios
WHERE datos ? 'telefono';
