¿Qué es PostgreSQL?

🗄️

Sistema de Gestión de Bases de Datos

PostgreSQL es un sistema de gestión de bases de datos relacional de código abierto, conocido por su robustez, confiabilidad y cumplimiento de estándares SQL.

⚡

Para Qué Sirve

Se utiliza para almacenar, organizar y recuperar datos en aplicaciones web, sistemas empresariales, análisis de datos y aplicaciones de misión crítica.

🔧

Características Principales

Soporta JSON, índices avanzados, transacciones ACID, stored procedures, triggers, vistas materializadas y extensiones personalizables.

💡 ¿Sabías qué?

PostgreSQL es considerado el RDBMS de código abierto más avanzado del mundo. Su nombre proviene de "Post-Ingres", siendo Ingres un sistema de bases de datos desarrollado en UC Berkeley en los años 60-70.

Arquitectura de PostgreSQL

PostgreSQL utiliza una arquitectura cliente-servidor con procesos múltiples para manejar conexiones y operaciones.

Cliente / Aplicación

psql, pgAdmin, aplicaciones, drivers

⬇️

Postmaster

Proceso principal que gestiona el cluster

⬇️

Backend Processes

Procesos por conexión (query executor)

⬇️

Storage Engine

Tablas, índices, WAL, buffer cache

📊 Procesos Background

  • Checkpointer - Guarda cambios en disco
  • WAL Writer - Escribe el log transaccional
  • Autovacuum - Limpieza automática
  • Stats Collector - Recopila estadísticas

💾 Almacenamiento

  • Tablespaces - Ubicación física de datos
  • WAL (Write-Ahead Log) - Durabilidad
  • Shared Buffers - Caché en memoria
  • Temp Files - Archivos temporales

🔒 Concurrencia

  • MVCC - Control de concurrencia multiversión
  • Row-level locking - Bloqueo por fila
  • Transaction isolation - Aislamiento de transacciones
  • Savepoints - Puntos de guardado

Ejemplos de Código

Crear Base de Datos

CREATE DATABASE mi_base_datos;

\c mi_base_datos;

Crear Tabla

CREATE TABLE usuarios (
    id SERIAL PRIMARY KEY,
    nombre VARCHAR(100) NOT NULL,
    email VARCHAR(255) UNIQUE NOT NULL,
    fecha_registro TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    activo BOOLEAN DEFAULT true
);

Consulta con JOIN

SELECT u.nombre, p.titulo
FROM usuarios u
INNER JOIN publicaciones p ON u.id = p.usuario_id
WHERE u.activo = true
ORDER BY p.fecha DESC;

Función JSON

SELECT 
    nombre,
    datos->>'telefono' AS telefono
FROM usuarios
WHERE datos ? 'telefono';
